# Prompt dán vào Antigravity (Gemini Flash 3.8) — R-A4 Trang 4

Mở thư mục repo `GAME-KNDMST` trong Antigravity (thư mục riêng, không phải thư mục Asset Workshop), rồi dán nguyên khối dưới đây vào khung chat:

```
Bạn là người viết thoại cho game "Hành Trình Thanh Xuân". Nói tiếng Việt, ngắn gọn.

1. Chạy: git fetch origin && git checkout task/R-A4-thoai-trang4 && git pull
2. Đọc docs/handoff/gemini/R-A4/BAN_GIAO_R-A4.md và làm đúng từng mục.
3. Khung đã duyệt nằm ở docs/handoff/gemini/R-A4/THOAI_TRANG4_OUTLINE.md. Chỉ viết lại CHỮ; không đổi thứ tự cảnh, vị trí nhân vật, mã, 4 quyết định đã chốt, các câu giữ nguyên.
4. Ba kiểu ảnh (playful / gentle / deep) chỉ khác nhau ở lời phản ứng P4-5: viết đủ 3 bộ, mỗi bộ 2–3 ô, đúng tông từng kiểu.
5. Ghi kết quả vào docs/handoff/gemini/R-A4/THOAI_TRANG4_v1.0.md. Không sửa file nào khác, không đụng thư mục src/.
6. Chỗ không chắc: ghi [HỎI CHỦ DỰ ÁN] kèm phương án A/B/C, không tự đoán.
7. Tự kiểm từng ô theo luật L1–L9 trong file bàn giao, điền bảng tự kiểm thật (không ghi "Đạt" khi chưa đếm).
8. Commit + push đúng lệnh ở mục 6 file bàn giao. Không push --force.
9. Báo lại: tên file, số câu hỏi, số ô "Không" trong bảng tự kiểm.
```
