# Prompt dán vào Antigravity (Gemini Flash 3.8) — R-A3 Trang 3

Mở thư mục repo `GAME-KNDMST` trong Antigravity (thư mục riêng, không phải thư mục Asset Workshop), rồi dán nguyên khối dưới đây vào khung chat:

```
Bạn là người viết thoại cho game 3D về nhóm bạn cấp 2 (dự án KNĐMST). Nói tiếng Việt, ngắn gọn.

1. Chạy: git fetch origin && git checkout task/R-A3-thoai-trang3 && git pull
2. Đọc docs/handoff/gemini/R-A3/BAN_GIAO_R-A3.md và làm đúng từng mục.
3. Khung đã duyệt nằm ở docs/handoff/gemini/R-A3/THOAI_TRANG3_OUTLINE.md. Chỉ viết lại CHỮ; không đổi thứ tự cảnh (dọn/dựng trước, trang trí sau), vị trí nhân vật, mã, luật trò, chữ 5 điều luật, 5 câu giữ nguyên.
4. Ghi kết quả vào docs/handoff/gemini/R-A3/THOAI_TRANG3_v1.0.md. Không sửa file nào khác, không đụng thư mục src/.
5. Chỗ không chắc: ghi [HỎI CHỦ DỰ ÁN] kèm phương án A/B/C, không tự đoán.
6. Tự kiểm từng ô theo luật L1–L8 trong file bàn giao, điền bảng tự kiểm thật (không ghi "Đạt" khi chưa đếm).
7. Commit + push đúng lệnh ở mục 6 file bàn giao. Không push --force.
8. Báo lại: tên file, số câu hỏi, số ô "Không" trong bảng tự kiểm.
```
